# 自动化配方：工作日站会摘要

> 来源：workbuddy-powerkit｜**修订 2026-10-19：路径占位符化 + 补充自建输入说明**
> 用法：把下方 rrule 与 prompt 通过 automation 工具创建定时任务；创建参数见文末。

## 用途

每个工作日早上 9 点汇总昨日完成 / 今日计划 / 阻塞三项，生成站会摘要，省人工翻记录。

## ⚠️ 使用前必读：本配方需要你自己准备输入源

v0.1 的输入源（`team-board.txt` + `team/` 目录）是多 Agent 团队协作的产物，**普通用户机器上并不存在**。直接创建会导致每个工作日空跑一次、输出「输入缺失」。

**创建前请二选一**：

1. **有团队协作**：在 `<INPUT_DIR>` 下维护 `team-board.txt`（一行一条进展，格式 `[日期] 姓名 | 完成/计划/阻塞 | 内容`）与 `team/` 产出目录。
2. **单人使用（推荐改法）**：把输入源换成你自己的工作区，例如直接扫 `<OUTPUT_DIR>` 下的 `*.md` 产出文件，把 prompt 的【输入】改为「枚举 `<WORKSPACE_DIR>` 下今日修改过的 `.md` 文件」。这样无需额外维护输入源。

## ⚠️ 占位符说明

| 占位符 | 含义 | 本机示例 |
|---|---|---|
| `<INPUT_DIR>` | 输入源目录（须含 team-board.txt 与 team/） | `E:/VST/2026-10-19-11-21-43/` |
| `<OUTPUT_DIR>` | 报告输出目录（**须已存在**） | `E:/VST/2026-10-19-11-21-43/` |
| `<WORKSPACE_DIR>` | 单人模式下的工作区目录 | `E:/VST/2026-10-19-11-21-43/` |

## rrule

```
FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=9;BYMINUTE=0
```

## Prompt（自包含，五要素）

【目标】生成本工作日站会摘要：昨日完成、今日计划、当前阻塞三段。
【输入】绝对路径：`<INPUT_DIR>/team-board.txt`（团队留言板，含任务进展记录）与同目录下 `team/` 目录中最近的产出文件列表。
【输出】写入 `<OUTPUT_DIR>/standup-YYYY-MM-DD.md`（YYYY-MM-DD 为当天日期）。
【约束】只读输入文件，不改写；无更新时输出「无更新」并正常结束，不得报错；摘要每段不超过 5 条；**不读取或输出任何凭据**。
【失败处理】输入文件不存在时，在输出文件首行注明「输入缺失：未找到 team-board.txt（若为单人使用，请按本文「单人模式」改写【输入】段）」并列出尝试过的路径，随后正常结束；输出目录不存在时先创建再写入。

## 创建参数

- `name`：`daily-standup`
- `prompt`：上方 Prompt 全文（**先替换占位符；单人使用请改写【输入】段**）
- `rrule`：`FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=9;BYMINUTE=0`
- `cwds`：`<OUTPUT_DIR>`
